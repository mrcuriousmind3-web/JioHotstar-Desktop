# Linux (.deb)

This project builds a Debian package for x86-64 Linux distributions that support .deb packages, such as Ubuntu, Debian, Linux Mint, and Pop!_OS.

## Download

After a successful GitHub Actions run, download the .deb from the workflow's Artifacts section. Once a versioned GitHub Release is published, the package will also be available under that release's Assets.

## Install

Open the downloaded .deb in your distribution's software installer and choose Install. You can also install it with your distribution's package manager if you prefer.

## Notes

- Linux distribution: Debian-based systems only.
- Architecture: x86-64 (amd64).
- This is an unofficial website wrapper, not an official JioHotstar application.
- A working internet connection and any required JioHotstar account/subscription are still needed.
